## Games Tech stack

Mostly folks are using Unity, it has multi-device support.
 
but also:
- ATARI Homebrew: Atari console game via assembly (cartridge with Raspberry Pi inside)
- At least one game had its own custom stack (Demons Happened)
- There was a custom 'gameboy like' device with its own games
  - probably a Raspberry Pi or similar in a 3D printed case

There were other interesting games, but those are the links I collected.
